# 快捷建筑

“快捷建筑（Quick Build）”把建筑魔杖、移动魔杖、寻路信标和 Light（照明）整合为一个 Fabric（织物）模组。玩家只需安装一个运行 JAR（Java 归档）。

## 主要内容

- 建筑魔杖：选择方块，绘制线、平面、实心体和中空结构。
- 移动魔杖：记录并整体移动包含方块状态、方块实体和空气的选区。
- 寻路信标：30 种编号寻路方块、ID 顺序重排器和 `/pfcancel <1-30>` 命令。
- Light（照明）：恒亮灯、16 色无线红石开关、发射器、手动连接器、感应器和红石信号延时开关。
- 快捷建造设置台：按物品名称分页显示设置、快捷键、命令和操作说明；建筑魔杖使用 4 页完整说明。

## 重要操作

- 两种魔杖的虚拟目标最远位于人物视线前方 4 格。
- 手持移动魔杖时始终显示准星虚拟方块；左键记录第一点，再左键记录第二点并立即保存原区域内容。
- 保存成功后原位显示结构投影；方向键移动、`Ctrl + 上下`升降、`Alt + 左右`旋转，最后左键确认移动。
- 移动魔杖搬运寻路方块时会同步更新线路节点坐标，原有光柱功能、线路顺序和连接关系保持不变。
- 每次切回有记忆区域的移动魔杖，服务端会同步端点并提示 `Ctrl + 右键`显示虚拟区域。
- 红石能量连接器：`Shift + 右键`设备 A，再`Shift + 右键`设备 B；重复同一对设备会断开；选择第一个点后`Shift + 右键`空气会取消。普通右键不执行连接操作。
- 红石能量感应器不再自动配对，必须手动连接；两个感应器必须同轴，中间为 `1～10` 格无障碍空间，空气和无形的原版光源方块均可通过。
- 感应器触发时输出强度 `15`，也会像红石粉一样接收并衰减传递相邻红石信号；外部信号断开后不会读取自己刚刚供电的红石粉。
- 红石信号延时开关支持 `0～3600` 秒，开启沿与关闭沿都会进入独立延时队列；两种模式都固定箭尾为唯一输入面，定向模式只从箭头输出，五面模式从除箭尾外的五面输出。
- 红石能量感应器不能作为延时开关的信号输入者，否则可能形成信号反馈并造成信号混乱。
- 魔杖设置中的 `256`、`1024` 和 `4096` 只是新存档初始值，不是最大值；保存后以服务端回传并写入存档的实际值为准。
- 快捷建筑页和设置台按“可设置物品优先、同类物品连续”的顺序排列；物品名称使用完整中文翻译。
- 30 种寻路方块允许所有玩家放置、调整和破坏；同一编号仍不能放在相同 `X/Z` 列，生存模式可用木镐或更好的镐正常破坏并掉落。
- 所有可放置的模组方块使用统一的短暂放置恢复时间，避免一次按键过快连续放置；魔杖和连接器不受影响。

## 旧存档

模组本体 ID（标识）为 `quick_build`，同时提供 `building_wand`、`pathfinding_beacon` 和 `light` 兼容标识。原有物品、方块、方块实体、网络与存档注册 ID 均保留旧命名空间，避免旧世界丢失内容。

安装前必须移除三个旧独立模组和旧测试捆绑包，不能同时加载。

## 构建版本

- Minecraft（我的世界）：`26.2`
- Java（爪哇）：`25`
- Fabric Loader（Fabric 模组加载器）：`0.19.3`
- Fabric API（Fabric 应用程序接口）：`0.154.0+26.2`
- Fabric Loom（Fabric 构建插件）：`1.15.5`
- Yarn Mappings（Yarn 命名映射）：不使用
- Mappings（命名映射）：Mojang Official Mappings（Mojang 官方命名映射）

当前正式版本为 `1.0.0`。按用户要求暂停 GitHub（代码托管平台）提交、PR（合并请求）和 Release（发行版）。

## 语言支持

内置 `en_us`（英语）、`zh_cn`（简体中文）、`zh_tw`（繁体中文）、`ja_jp`（日语）、`ko_kr`（韩语）、`de_de`（德语）、`fr_fr`（法语）和 `es_es`（西班牙语）。所有玩家可见文字使用翻译键；英语和中文为主要校对语言，其他语言为首版翻译。
