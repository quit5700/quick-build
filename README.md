## 语言支持

模组内所有玩家可见文字均使用翻译键，不在 Java（爪哇）源码中硬编码显示语言。当前内置英语、简体中文、繁体中文、日语、韩语、德语、法语和西班牙语。英语和中文为主要校对语言，其他语言为首版翻译，欢迎继续校正游戏术语。

新增界面、提示、物品或命令反馈时，必须同步维护八种语言；`LocalizationResourcesTest`（本地化资源测试）会检查语言文件、键集合、缺失键和 Java 中文硬编码。
