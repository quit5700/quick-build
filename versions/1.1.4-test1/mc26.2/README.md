新增删除法杖，外观沿用 1.1.4-preview1 的红色晶体模型、游戏物品栏图标。
左键确认第一点、第二点和最终删除；右键取消第一点或待确认范围。范围为包含端点的长方体，不设人为边长或体积上限。第二点确认后用红色边框显示整个范围，不枚举所有方块。
左右键拦截普通攻击、挖掘、放置、容器打开与实体交互。切换物品、断线或切换维度会取消尚未确认的选区；已经确认的任务保存到对应维度，玩家离线或离开该维度时暂停，返回继续。
服务端每维度每刻最多处理 2048 格，并有 4 毫秒软时间预算。异步请求当前区块，不等待未完成的区块任务，处理后释放专用票据。一次每人每维度执行一个删除任务，限制任务并发，不限制选区。
直接将方块替换为空气，不生成挖掘掉落；普通容器内容先清空。正常邻居更新和特殊模组方块的移除回调仍执行。遵循建造权限、原版世界边界与出生点保护。已确认的删除没有撤销功能。
设置台在移动法杖后增加两页介绍，保留既有界面布局。创造模式模组物品页新增物品。配方为红石块、木棍、钻石从上到下竖排，使用原版配方系统，JEI（物品与配方查询）自动收录；没有 JEI 也可使用。
