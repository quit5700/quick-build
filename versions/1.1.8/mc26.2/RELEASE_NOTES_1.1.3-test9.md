# 1.1.3-test9（测试版9）交付说明

本版本源码位置为 versions/1.1.3-test9/mc26.2。根目录 mc26.2 保留测试版8及此前已暂停的延迟诊断工作，不是本次安装包的源码。

## 本次改动

- 原可变恒亮灯改名为可调恒亮灯，普通灯只提供“两点区域满亮”和“两点真实照明”。移除原版无形光源、局部白昼、混合与画面增亮的普通灯界面入口。
- 两个模式在同一居中下拉菜单中连续排列；展开时隐藏被菜单覆盖的选区按钮和提示。选择按钮、红石状态、确定／取消、真实照明警告按纵向分区排列。未定义选区时显示先选择并确认范围的提示。
- 旧普通灯的非区域模式读取后迁移为两点区域满亮，保留已有选区；没有选区时不猜测范围，等待重新选择。已供电旧真实光源模式通过既有任务系统排队清理，不清除世界或任意方块。
- 复制灯移除创造物品栏入口和合成配方；已有设置台列表本来就没有复制灯。增加 JEI（物品配方查看器）可选隐藏插件，避免其搜索列表仍显示复制灯。旧方块／物品注册和原有行为保留，已有世界中的复制灯不删除。
- 16 色红石能量远程开关仅替换物品栏使用的独立图标，64×64 透明纹理。长方形底座分别配色，黑色圆球头、白色摇杆和红色指示点保留。放置方块、手持、掉落与展示框模型文件不变。
- 八语言名称、使用说明和新增提示同步更新。内部注册标识和旧模式序号不变。
