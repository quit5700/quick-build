## 拖动根因与修复

版本适配及客户端缓存逻辑问题。AuxRenderer 缓存的面和材质模型保存绝对世界坐标，renderKey 又包含平移和旋转。连续拖动时每个姿态改变都重置体素遍历，普通蓝图必须等全部网格完成才替换旧网格。大选区在连续移动期间没有足够时间完成，所以旧彩色网格停留，结束后才刷新。原生选区边框和蓝图彩色表面是不同绘制部分，不能用单独边框跟随代替彩色表面跟随。

独立原客户端复现：64×64×64 蓝图暖机后，连续移动40次，实际黄色表面只有1个采样跟上。生产修复限于 mc1.21.1 的 AuxRenderer.java、AuxRow.java 和新增 AuxRenderPose.java。将几何身份与姿态分开，姿态变化时可直接映射已完成网格的方块坐标、面朝向和材料朝向，持续体素扫描无需因每步拖动重新开始。保留每帧体素预算、建筑生成任务的进度过滤及取消清理。没有可用完整网格时可显示已经完成的部分。静止行沿用原缓存直接绘制。

新增 AuxRenderPoseTest 检查连续80次平移、已有旋转基础上的三轴相对旋转、取消回原位，以及确认后几何身份稳定与形状变更失效。材质朝向和真实提交在完整游戏客户端检查，避免普通单元环境加载不完整 Fabric 注册表。

## 已尝试失败及后续避免

- 1.21.1 初版客户端探针在持有法杖的首次维度初始化前设置选择，随后被正常初始化清空。延长等待未解决，加入逐帧选择、缓存游标及截图后确定原因。最终探针在初始化后维持选择，旧版实际40次拖动复现仅1次跟随。前期探针日志保留。
- 新工作版本遗漏 1.20.1 的本地 libs 依赖目录，配置阶段无法找到 Jade 归档。补齐原版本声明的本地依赖，不改动依赖版本。
- 新增辅助类的中文注释触发本项目禁止 Java 源码出现汉字的既有检查。改用无汉字代码注释，玩家文字继续统一使用八语言翻译资源。
- 普通单元测试直接 Bootstrap 会加载测试环境未注入的 FabricRegistry。材质朝向检查移入真实客户端，普通单元测试保留纯坐标和姿态逻辑。未弱化既有测试断言。
- Gradle 9 与 Java 25 将缓存目录链接规范化为包含中文的实体路径，导致 UTF-8 参数文件在原生启动时无法定位 GradleWorkerMain。仅使用英文别名的旧方案已尝试失败。改用 H:/CodexWork/q5-gradle-cache 实体缓存入口。尝试移动仍被占用的旧缓存目录失败后，采用独立实体目录并复用不可变依赖文件。源码、测试和中文存档场景仍在中文目录验证，不要求用户更改中文环境。
- 后续复制跨版本项目必须包含声明的 libs 依赖。渲染回归必须观察实际提交的表面坐标，测试移动中间状态、取消和确认，不能仅验证最终位置。
## 最终实现补充

纯平移采用缓存的长整数偏移，复用原面方向、边界及材料状态，避免每个面重复拓扑判断。局部视点每跨16格或旋转改变时可重新扫描，以保留大位移后的裁剪刷新；现有完成网格在扫描期间仍随当前姿态移动。材料模型按行保留来源，再按变换后的世界方块位置与状态去重，兼顾原地重叠和移开后的两个形状。

最终探针先等待完整网格，再连续更新目标位置，按真实绘制帧采样；取消和确认也等待实际绘制帧后核对。早期探针按游戏刻读取计数，没有画面的游戏刻会造成假失败，已保留失败记录并纠正采样层次。完整资源缓存已复用，额外客户端验证跳过重复资源下载任务，不跳过功能断言。独立服务器使用默认平坦世界参数时的缺少 layers 日志为夹具地形配置提示，测试在明确设置的坐标和方块上运行，结果以各项断言与正常退出为准。
