# 快捷建筑公共物品页接口 v1

本接口首次提供于1.1.9-test1测试版，支持本次八个Fabric（模组框架）版本，1.1.8没有此接口。其他模组不需要修改快捷建筑源码，也不把自己的物品注册到快捷建筑命名空间。

## 推荐接入

复制examples/QuickBuildPageCompat.java到自己的模组，调整package（包名）。在本模组ModInitializer（模组初始化入口）中注册完自己的物品后调用：

```java
boolean integrated = QuickBuildPageCompat.register(
    "your_mod", 100, "tools",
    java.util.List.of("your_mod:terminal", "your_mod:link_tool")
);
```

示例标识your_mod:terminal等必须替换为本模组已注册的实际物品。列表使用完整物品标识字符串，而不是Item（物品）对象，避免八版命名映射差异。示例没有强引用快捷建筑类，可在不安装快捷建筑时运行。未安装或仅安装无接口的旧版时返回false，保留自己的物品页。推荐自己的物品页始终保留。不要把这段接入包装器当成接口实现复制进快捷建筑，也不要打包快捷建筑运行包到自己的JAR（归档）里。

## 直接依赖接入

若快捷建筑是必需依赖，可直接调用cn.quit5700.quickbuild.api.Q5ItemPage.register，参数同上。开发环境按目标Minecraft（我的世界）版本添加快捷建筑构建产物为modCompileOnly（仅编译模组依赖），运行时使用对应游戏版本的运行包；fabric.mod.json（模组元数据）depends（必需依赖）中声明quick_build >=1.1.9-test1。可选反射接入仅在suggests（建议依赖）中声明quick_build，不放入必需依赖。

## 顺序和去重规则

快捷建筑自己的原有物品保持在前。外部组按order（排序值）升序排列，再按modId（模组标识）和groupId（分组标识）字典顺序排列；同组内部保持列表顺序。同一物品完整标识在本接口控制的列表内只出现一次；它与快捷建筑原有物品重复时不再追加。与原版Fabric事件直接修改列表的第三方模组不共享本登记表，不能保证那些修改的排序和去重。

组的唯一键是modId+groupId。同组重复register（登记）会完整替换原物品和排序值，不是累加。unregister(modId, groupId)（取消登记）返回是否移除了组。标识限合法小写命名空间和路径；参数错误会抛出异常，注册更新是原子的，旧登记不会被半覆盖。未注册的物品标识和空气在物品页构建时跳过，不生成占位；因此务必检查拼写并在注册物品后登记。注册时复制列表，后续修改调用方列表不会改变已登记内容。

建议在初始化时登记并避免高频运行时更新。登记表在每次游戏构建物品页时读取，不缓存Item（物品）实例；不承诺登记调用自动刷新已经打开的创造界面。不得用于服务端库存同步、箱子内容聚合或物品数据存储。

## 冲突与限制

物品注册冲突是完整注册标识重复，应使用自己的唯一modId。物品页只顺序追加，不指定格子，不会覆盖同一格；安装、卸载、新增组后后续格子会顺延。优先级相同也稳定，但不保证永久固定行列。

## 版本接口

八版公共类名、API_VERSION（接口版本）1和字符串参数一致。26.2、26.1.2、1.21.11内部使用Identifier（资源标识）；其他版ResourceLocation（资源定位符）。26.x的创造页构建器和旧版FabricItemGroup（物品分组）差异由快捷建筑内部适配，调用方不需要触及其物品页类型。示例只需Fabric Loader（加载器）和Java（爪哇）反射，不依赖这些游戏类。

回归覆盖排序、加载顺序独立性、分组、物品顺序、内外去重、同组替换、不可变快照、取消登记、错误登记不污染状态及空组。游戏内多个独立模组实际接入的画面仍需实测，不以编译替代验收。
