# 快捷建筑 1.1.9／Minecraft（我的世界）1.20.4

本目录是该游戏版本的完整正式版源码，包含资源、八语言翻译、自动测试、Gradle（构建工具）包装器和本地编译依赖。具体环境见 VERSION_INFO.md。

使用根目录 scripts/release_119.py 构建、验证；普通构建命令为 .\gradlew.bat test build。Gradle用户缓存和Java临时目录请按根目录说明设置到H盘。运行包和源码归档生成在本目录dist，不将源码归档放入游戏mods目录。

功能包括建筑、蓝图、移动、删除法杖、生成箱和照明／信标组件，具体操作以游戏说明台为准。生成箱由法杖确认任务后自动生成，没有普通合成配方和手动放置入口。新增功能应保留本版接口差异和防回归测试。
