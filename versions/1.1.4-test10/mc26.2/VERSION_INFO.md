# 快捷建筑1.1.4-test10：26.2结构建造测试版

本版本基于测试版9，保留已验收移动、删除法杖及建筑四模式。默认单块；潜行＋右键选材料，普通右键在没有选点时切模式，有选点或运行任务时取消。两点后左键确认、右键取消；每把法杖记忆模式和材料，切换物品保留选点并闪烁。

本次修改：栅栏、墙、玻璃板在放置时依据当前完整邻居校正连接，并校正边界相邻连接方块；后续放入邻居时再次校正。箱子按单箱放置，密集排列不自动合并，新箱为空，不复制样本内容。

床、门及双格植物按完整两格结构放置，先写齐整组，再检查生存条件、通知周围；失效时恢复原位置，不扣材料。单块模式点击放一个完整物品，占用该物品所需两格。区域任务以第一点方向排列，床沿X轴，X只有一格时沿Z轴；空心优先选可完整配对的水平轴。门、双格植物垂直配对。

实心模式把完整结构从第一点排到第二点，末端无法配对的格子设为空气。空心模式只放与外边界接触的整组，多格厚度向内占用，内部深处仍保留；偶数可配对尺寸两侧边界保持。按用户补充，奇数尺寸也执行，例如49×49从第一点开始建造完整床，无法配对的末端留空，不拦截、不扩张选区。合法空间只有一格时该轴无法容纳整组，按余格规则留空气。

区域替换选多格建造材料时，在选材料、进入模式和两点确认时显示红字：请不要替换多格物品，会损坏结构。仍可左键确认继续，按实心排列规则执行。现有类型过滤、空气跳过和保护仍有效：整组任何格不匹配或受保护，整组不放置；余格清空同样经过保护。受保护方块不能因警告确认而绕过。放入箱子等受保护方块后，今后不能再用区域替换替换它们；其他操作仍按各自原规则。

生存每个完整床、门或双格植物消耗一个对应物品，缺料前不放半个结构，背包补料后自动继续，右键可取消。空气余格不耗材料。进度按实际放置占用的方块数计算，空心额外厚度计入总量，余格空气不计入放置量。无人为建造数量上限，保持分批任务和保存恢复。

箱子本身始终受保护。纠正原保护逻辑把水平方向相邻箱子也当成附着物支撑的误判，允许连续把普通方块替换为单箱；红石底座、墙面按钮等实际支撑保护保留。

Q5模组方块说明台新增两组说明，使用现有自动换行、分页和按钮布局。八语言提供一致的键和参数。此次未扩展楼梯朝向、流体材料和其他模组私有多格结构接口；床、门、双格植物类别及其兼容子类支持，其他模组特殊结构需分别验证。普通方块仍执行原版放置回调、重力和流体更新。
