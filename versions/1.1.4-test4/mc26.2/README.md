# 快捷建筑 1.1.4-test4：建筑与移动法杖操作更新，26.2测试版

建筑法杖默认单块放置，每把法杖保存模式。潜行+右键已有方块选材料；普通右键在无选区时依次切换单块放置、实心填充、空心外壳。法杖不攻击、不挖掘、不操作容器。

单块模式左键一次放一块。实心与空心模式左键依次选两点，再次左键确认建造；有选点时普通右键取消。范围包含两端点。空心模式只建最外层，内部原有方块保留；一格、两格厚的区域没有内部空间，因此全部放置。

切换其他物品保留建筑选区，切回显示高亮，选点期间物品栏图标周期明暗。未确认选择在退出世界、断线、切换维度时清除。建造任务记录在对应维度，玩家离线、离开维度、执行法杖不在背包时暂停。

建筑没有人为数量上限，使用常量空间游标从第一点向第二点逐列分批施工。每维度每刻2048格、4毫秒软预算；空心仅在边界放置，不改内部。显示已放置数量与目标总数。生存每成功放一块消耗一个对应材料；不足时暂停，背包补料自动继续。任务材料在确认时固定，之后选其他材料不改变任务。手持执行任务的法杖普通右键取消，已经完成部分保留。生存遇障碍、权限禁止或没有支撑时暂停，清除障碍、补充支撑后继续。创造不消耗材料并可覆盖方块。
