# 快捷建筑模组总结

## 基本信息

- 模组名称：快捷建筑（Quick Build）
- Mod ID（模组标识）：`quick_build`
- 当前版本：`1.0.0` 正式版
- Minecraft（我的世界）：`26.2`
- Java（爪哇）：`25`
- Fabric Loader（Fabric 模组加载器）：`0.19.3`
- Fabric API（Fabric 应用程序接口）：`0.154.0+26.2`
- Fabric Loom（Fabric 构建插件）：`1.15.5`
- Mappings（命名映射）：Mojang Official Mappings（Mojang 官方命名映射）

快捷建筑将建筑魔杖、移动魔杖、寻路信标和 Light（照明）整合为一个 Fabric（织物）模组，只需安装一个运行 JAR（Java 归档）。模组保留 `building_wand`、`pathfinding_beacon` 和 `light` 三个旧兼容标识及原注册 ID，便于旧存档继续使用。

## 主要内容

### 建筑魔杖

- `Alt + 左键`记录准星所指方块，鼠标悬停物品时显示当前选择。
- 左键短按立即放置单个方块。
- 左键拖动可绘制线、平面或实心建筑体。
- `Shift + 左键`拖动固定绘制平面；短按两次按两个点生成线、平面或实心体。
- `Ctrl + 左键`拖动生成实心结构；短按两次生成中空平面或中空建筑体。
- 一维范围不能中空，只会生成普通实心线。
- 松开按键后保留虚拟预览，调整完成后再次左键确认建筑。
- 方向键移动整个预览，`Ctrl + 上/下`调整整体高度。
- `Shift + 方向键`移动第二点，`Shift + Ctrl + 上/下`调整第二点高度。
- `Shift + 右键`取消当前虚拟区域。
- 创造模式不消耗材料，可悬空放置并替换已有方块。
- 生存模式消耗背包材料，整个结构至少需要一个方块获得外部支撑；材料或条件不足时整片预览变红且不会放置任何方块。

### 移动魔杖

- 第一次左键记录第一点，第二次左键记录第二点并保存范围内全部方块和空气。
- 记录完成后原位置保留虚拟区域。
- `Ctrl + 右键`显示已记录区域的移动投影。
- 方向键移动投影，`Ctrl + 上/下`调整整体高度。
- `Alt + 左/右`以区域中心旋转 `90` 度，向右为顺时针。
- 投影位置确定后左键执行移动，成功后自动忘记记录。
- `Shift + 右键`主动忘记当前记录。
- 搬运寻路方块时同步更新节点坐标、顺序和连接关系，光柱功能保持不变。
- 移动红石装置前应保持装置静止；红石开关连接状态会被清零。

### 寻路信标

- 提供 `1～30` 号寻路方块，同号方块组成贯穿世界高度的寻路线。
- 同一编号不能放在相同 `X/Z` 列。
- 所有玩家都能放置、调整和破坏寻路方块。
- 生存模式可用木镐或更好的镐破坏并获得掉落物。
- ID 顺序重排器依次右键两个不同的同号有效方块，可连接断开的线路或调整节点顺序。
- `/pfcancel <1-30>`：删除当前维度指定编号的全部寻路方块和光柱，不产生掉落物。

### 照明与无线红石

- 恒亮灯：收到红石信号后提供亮度 `15`、半径 `14` 格的无衰减照明。
- 红石能量远程开关：提供 `16` 种颜色，右键切换对应颜色网络状态。
- 红石能量发射器：网络触发时从六面输出强度 `15` 的红石信号。
- 同色设备连接数量不限；不同颜色普通设备不能直接合并。
- 红石能量连接器使用 `Shift + 右键`依次选择两个设备进行连接或断开。
- 选择第一个设备后，`Shift + 右键`空气或连续选择同一设备可取消。
- 连接器禁止跨维度连接，普通右键不会进入连接流程。
- 安装 Jade（玉）后可直接查看部分网络信息。

### 红石能量感应器

- 不会自动配对，必须使用连接器手动连接。
- 两个感应器只有在同轴且中间存在 `1～10` 格无障碍空间时才能形成感应线。
- 空气和无形原版光源方块不算阻挡，其他方块会阻挡感应线。
- 实体经过感应线时输出红石信号，也能向相邻红石元件衰减传递信号。
- 感应器允许接入不同颜色的无线红石网络。

### 红石信号延时开关

- 右键打开设置界面，延迟范围为 `0～3600` 秒。
- 输入开启和关闭都会按设置时间完整延迟，短脉冲不会丢失。
- 两种模式都固定以箭尾为唯一输入面，箭尾永远不输出。
- 定向模式仅从箭头面输出强度 `15`，其他四面不导电。
- 五面模式从除箭尾外的五个面输出，其他五面不能作为输入。
- 模式、延迟和待处理变化会随区块存档保存。

> **已知限制：红石能量感应器不能作为延时开关的信号输入者，否则可能形成信号反馈并造成信号混乱。**

### 快捷建造设置台

- 右键打开统一设置与说明界面。
- 按物品分页显示设置、操作方法、命令和注意事项。
- 可调整建筑魔杖平面、建筑体和移动魔杖区域的数量设置。
- 默认值不是人为最大值，用户可以继续增大，但过大的区域可能造成明显卡顿。
- 设置为存档全局设置，所有维度共用；单人可修改，多人默认仅 OP（管理员）可修改。

## 创造物品页与兼容性

- 只注册一个创造物品页，中文名为“快捷建筑页”，使用工作台图标。
- 快捷建造设置台排列在物品页首位，其余物品按功能分组。
- 原三个独立模组已经合并，安装正式版前必须移除旧独立 JAR 和测试捆绑包。
- JEI（Just Enough Items，物品管理器）可显示已注册的原版配方。
- Jade（玉）为可选兼容模组，不是运行必需依赖。

## 性能与安全提示

- 两种魔杖的准星虚拟目标最远位于玩家视线前方 `4` 格。
- 大范围虚拟预览和一次性方块操作可能造成客户端或服务器卡顿。
- 魔杖数量设置没有模组人为上限，但代码会避免 Java 整数溢出。
- 所有可放置的模组方块使用统一的短暂放置恢复时间，避免一次按键过快连续放置。
- 建议移动复杂红石结构前备份存档，并确保装置处于静止状态。
