## 已失败方案，禁止无证据重复

1. 沿用原版canBeReplaced限制：普通土块、原木乃至相同原木导致生存批量建造暂停，违背整区域覆盖要求。
2. 只删除位置占用限制：遗漏容器掉落、多格方块实体保护及末端空气清理对基岩的绕过，不能直接交付。
3. 只removeBlockEntity再放多格结构：Minecraft在旧方块状态仍存在时，getBlockEntity会即时重建空方块实体，触发旧结构保护检查。修复为先完整快照，再静默移除旧状态，完整放置后才提交内容物掉落；失败恢复状态和保存数据。
4. 单块原路径先clearContent再setBlock：会抑制正常容器掉落；生存解禁覆盖后会暴露物品丢失，必须成功后一次性掉落。

本批缺陷详情与实际验证结果见docs/bugs/BUG-20261005-SURVIVAL-SOLID-OCCUPIED.md。不得把本表当作其他四版已经验证通过的证明。
