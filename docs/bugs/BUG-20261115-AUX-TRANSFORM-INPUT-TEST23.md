## 根本原因及复现证据

1. `beginTransform` 仅提取复选框中已放置的行，当前编辑行 `active` 没有被使用。用户未勾选时直接静默返回；按钮仍可点击，也没有界面提示。旧版实际鼠标证据：21:23:41 清空勾选，随后点击旋转／移动仍停留菜单；21:24:00 关闭菜单，21:24:12 再左键，进入 `first=BlockPos{x=5032,y=157,z=180}`，聊天显示第一点已选定，符合回到已有形状编辑的现象。
2. 左右键与退出键只按游戏刻轮询按住状态，按下、松开都发生在两个游戏刻之间会漏识别。旧版右键多次不打开菜单；21:22:48 按退出键打开暂停界面，返回后仍 `transform=true attached=true`。不能只用直接设置预览验证输入。
3. 排除了单纯菜单点击必定串入连接的推断：旧版勾选后实际按钮点击保持 `attached=false`，下一次真实左键才连接。此次仍用事件发生前的界面状态过滤菜单鼠标事件，保留该行为。

## 修改文件及修复方式

生产修改仅位于 `versions/1.1.9-test23/mc1.21.1`。`AuxTransformSelection.java` 在有明确勾选时只操作勾选的已确定范围行；没有勾选时使用当前已确定范围行；当前为空白行时拒绝，不能错误操作其他行。活动编号已失效而且仅一个有效形状时可回退到该形状。返回快照供预览，进入时同步固定选择，提交与预览使用相同编号。

`AuxClient.java` 使用上述选择规则；空白或无可用形状时通过当前界面状态栏显示翻译提示。鼠标事件进入 `AuxClickInput.java`，按顺序每刻消费一次，菜单内点击不进入场景队列，取消时清理队列。`AuxMouseMixin.java` 在原生鼠标按下回调入口记录事件，保留原滚轮逻辑；新增 `AuxKeyboardMixin.java` 在退出键原生回调取消预览，避免短按漏掉，暂停菜单原有行为保留。`quick_build.client.mixins.json` 登记新增回调。八语言 `building_wand/lang/*.json` 新增一致翻译键，无玩家硬编码文字。新增 `AuxTransformSelectionTest.java`、`AuxClickInputTest.java`。

未修改服务端形状、生成箱规则、工具耐久、渲染网格和保存格式。测试22移动跟随、生成箱无配方与非手动获取、测试21设置台背景修复均保留。仅更新 1.21.1，其他九版仍保留原交付。

## 已尝试失败与后续避免

复制整合模组到开发命名空间后，Iris 在 `MixinLevelRenderer` 映射选择器解析时遇到空描述符，启动失败；不得据此认定用户正常启动也有冲突，不得删除原目录光影模组。已改用用户实际库及普通生产命名空间启动，全部原模组副本成功进入世界。两种启动日志分别保留。原生 glfw.dll 启动异常仅出现一次，后续启动成功，不将其冒充已理解根因并修复的模组缺陷。

以后进入操作模式不能在无有效选择时静默返回；预览、确认必须固定同一选择。输入测试必须覆盖快速按下松开、界面关闭、取消和真实服务端结果。不要用注入变换字段或直接调用确认函数代替操作链。本轮只验收独立测试世界，用户原存档的特殊数据与长期使用手感仍由用户复测。
