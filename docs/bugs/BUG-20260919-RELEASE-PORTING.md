# 1.1.3 跨版本适配记录

项目根目录：C:/Users/quit5700/Documents/mc虚拟线路模组/快捷建筑模组。
范围：versions/1.1.3 下八个版本。类型：版本接口适配、构建依赖、加载配置与历史回归。

## 现象与原因

- 1.21.11 编译找不到 ServerEntityLevelChangeEvents、PlayerLookup.level：26.x 接口更名，旧版应使用 WorldChangeEvents / world。已尝试失败：直接照搬 26.x 事件名称。
- 1.21.4 无关红石类和渲染钩子出现新接口：适配脚本按原始字节对比文本，CRLF/LF 换行差异误判为逻辑修改。已尝试失败：用字节比较判断 Java 文本是否变更。
- 1.21.4 的遮挡形状方法不接收世界/位置，而 1.21.1 及更旧版需要：以目标实际 API 为准，不按“旧版”统一替换。
- 1.21.1 及更旧版没有 ClientLevel.setSectionRangeDirty：改为每个区段调用 LevelRenderer.setSectionDirty，维持原有队列和预算，不实现已取消的延迟优化。
- Java 17 不支持 List.getFirst/removeFirst/addFirst，Java 21 不支持 Java 25 Class-File API：列表使用索引等价操作，三个初始化回归用 ASM 读取同样的编译后调用关系。
- 1.20.4 旧测试按原始文本匹配“mixins 数组仅有客户端配置”，新增公共配置后失败：正确要求是客户端配置仍被注册。改为 JSON 解析检查注册，同时新增公共配置必须存在的断言；原渲染类型覆盖检查全部保留。
- 1.21.1 的已有带电光源恢复测试失败：新版本覆盖了该分支已有的 hasSource/reconcile 恢复逻辑。恢复原来的缺失光源重建及安装优先顺序，原测试不修改。
- 公共混入配置来自 26.2，兼容级别仍是 JAVA_25：各版本按 gradle.properties 的 Java 版本设置，避免编译成功但加载失败。
- 1.20.1 原固定 Jade 11.13.1 编译依赖下载时 Curse Maven 的 TLS 握手失败；PowerShell 同站下载也失败。通过发布者 CurseForge 文件页核对文件 6291330 和名称，从 ForgeCDN 获取同一固定文件，存于该工程 libs，仅编译使用，不嵌入运行包。不关闭证书校验，不降低 TLS 安全设置。

## 修改与验证

修改包括各目标工程的网络、存档、客户端选区渲染、公共混入配置、必要的版本专用接口和适配脚本。1.21.1 及更旧版增加仅 GUI（物品栏界面）替换开关模型的加载钩子，保持世界与手持模型；1.20.x 补齐旧版 loot_tables（战利品表）目录。

构建从各自中文路径运行；所有文本读写明确 UTF-8。每个版本完成后执行完整 build（构建及测试），具体计数、归档哈希与安装清单见 versions/1.1.3/发布核验.json。未获得用户实机验收的移植版本，不把自动测试等同实机验证。
