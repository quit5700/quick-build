## 现象与原因

界面布局：删除介绍翻页按钮覆盖正文。原按钮位置依赖不适用的固定限制区锚点，没有使用正文真实换行高度。
状态逻辑：第一点在切换其他物品后丢失。客户端离开法杖分支和服务端持物检查清除了选区。
渲染更新：用户确认空手与视角移动无效，F3+A重载后恢复，指向客户端区块网格更新问题。尚不能证明Sodium（钠渲染优化模组）内部具体原因，未把猜测当作确定根因。
新增生存规则：旧版没有耐久、基岩过滤和容量确认机制。
版本接口：Component（文本组件）变量不能调用MutableComponent（可变文本组件）的withStyle（设置样式）方法，首次编译失败。改为局部类型推断保留实际返回类型后通过。
中文路径与执行目录：曾把仓库相对路径用于版本目录，导致脚本找不到文件和修复未写入；该调用方式已尝试失败。之后编辑使用仓库根目录或绝对路径，构建独立指定版本目录。

## 修改与修复

SettingsScreenLayout、WandSettingsScreen按正文高度分分页和定位按钮。
DeleteSelectionMemory、DeleteWandClient、DeleteWandServer保留跨持物选区，并通过服务端查询恢复，维度和断线清理。
物品GUI（图形界面）原生模型条件与CustomModelData（自定义模型数据）标志实现周期明暗。
DeleteWear、DeleteWandData、ModItems记录512耐久、100块计费和每杖余数；原版耐久附魔机制保留，经验修补标签补齐。
DirectedDeleteCursor、DeleteTaskData、DeleteTaskState从实际第一角开始分批删除并持久保存工具标识；成功删除才计费，生存基岩过滤，损坏停止。
DeleteWandServer分批预检，在预计耗尽时红字告知，确认前不删除。
DeleteNetworking、DeleteMeshRefresh、SectionRefreshQueue通知已改区块并延迟合并局部网格重建，不使用全世界强制重载。
八语言、README（说明文档）、VERSION_INFO（版本信息）更新。
