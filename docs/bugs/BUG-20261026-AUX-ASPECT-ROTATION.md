# 26.3辅助界面比例、初始空行与截面向下

范围：当前Git仓库快捷建筑模组；以已安装1.1.9-test6为基线，独立1.1.9-test7，仅26.3。用户授权完成本批后一次性关机，不沿用其他任务的旧关机条件。

现象：主设置过宽过矮，生成材料信息与格子分散，额外−64按钮冗余；首次打开自动出现一行；移动/旋转中难以让截面朝下。

类型：交互逻辑、状态保存、界面布局。

根因：Base按行数压缩主界面高度，新增按钮固定靠底；生成箱按底部倒推网格、侧边大按钮和材料条数各用一套分页，宽扁并割裂内容。query读取接口顺便写入空行，左键在无行时也自动创建。旋转所有轴均用玩家yaw（左右朝向）角，完全遗漏pitch（俯仰）；滚轮切轴时直接清零当前角度，未将其组合进入待提交变换。

修复前：新增真实输入计算回归，旧计算5项中4失败，保留旋转修复前.log及XML（测试报告）。纯几何旋转矩阵测试仍通过，说明问题位于输入与提交链，不能重写形状截面。另一次检查误调用compileClientJava任务失败；本项目src/client并入main，已改用真实test任务，其编译包含客户端，保留失败日志，不改构建结构。

修改文件：test7/mc26.3下AuxRotationGesture.java、AuxClient.java、AuxServer.java、AuxUiLayout.java、AuxScreens.java、AuxRotationGestureTest.java、AuxUiLayoutTest.java及building_wand八语言。独立实机探针在outputs/20261026_辅助比例与朝向_test7、scripts/probe_aux_ui_test7.py。

修复方式：主界面限制宽高比，新增行按钮跟随实际可见行，空白保留其下；生成箱纵向排列材料信息、九列三行材料格、翻页/执行、九列背包与快捷栏、进度和底部操作，统一格子，移除−64。材料格仍只投当前欠缺材料，可点击取回；玩家背包按9至35、0至8映射显示，未改真实物品槽号。首次query只读取，不自动写行；无行左键提示去设置新增；原保存记录保留。横轴用俯仰，竖轴用左右转头；切轴将既有旋转积入序列，预览和服务端共用同一组合规则，变换仍按原有全部校验后提交，兼容旧单轴请求，不改SavedData存储格式。

当前验证：相关单元已通过，独立整合客户端正在验证空行、实际点击新增、射线连接、低头旋转朝下、切轴、平移及服务端确认，另复查宽窄窗口全部相关弹窗和既有星形/半月生成。完成前不得声明已安装或已修复。

避免重复：形状几何正确不代表输入可用；按真实鼠标/键位链验证，不能只调用矩阵函数。查询不应隐式创建用户记录。材料列表和材料格共用27格分页，不再使用两套页容量。保留测试6已验收的字体、像素缩放、星形/半月轮廓和支撑更新，不改其他八版。

画面复核补充：界面验证_1在小窗口发现箱体宽高比不达标，修正宽度随可用高度收敛；界面验证_2已有3916项通过，但人工截图发现小窗口执行按钮与翻页交叠，原测试只查面板边界未检查控件相交，因此新增生成箱所有控件两两不交叠断言，执行按钮随网格宽度缩短文字，完整说明保留悬浮提示。上述通过不能作为最终视觉结论；等待验证_3。
