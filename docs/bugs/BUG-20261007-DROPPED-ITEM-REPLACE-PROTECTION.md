# 掉落物误触发区域替换实体保护

当前项目根目录：C:\Users\quit5700\Documents\mc虚拟线路模组\快捷建筑模组
类型：核心逻辑、实体保护。
现象：掉落物碰撞范围或其脚下位置可能阻挡区域替换。
根因：ReplacementRules.protectedPosition查询所有存活实体，误包含ItemEntity（掉落物实体）。
修复：六版ReplacementRules.java的查询谓词仅排除掉落物，其他实体分支和生产文件不变。
复现：26.2原生产代码下原57场景通过、新增碰撞与脚下两场景失败；日志保留修复前复现_mc26.2.log。
验证：每版保留原57场景，新增两种真实掉落物测试，验证查询可见、任务成功且掉落物数量与存活状态保持；完整单元与世界回归通过。
已尝试失败：1.21.4旧火把掉落测试使用getEntitiesOfClass观察远端未激活区块，掉落数量漏报；依据当前项目1.21.1同类记录仅在烟雾测试恢复完整实体分区观察，保持原数量断言与观察范围，不改生产掉落。首次观察修正后复用旧测试世界产生遗留掉落物数量干扰；保留失败日志，最终更换全新测试世界，未修改正确数量断言。失败日志已保留。
