# 四版建筑法杖耐久与配方修复

项目根目录：C:/Users/quit5700/Documents/mc虚拟线路模组/快捷建筑模组。
类型：工具核心逻辑与跨版本资源同步。当前状态：1.1.8-test2四版构建、验证、安装及测试杖放入完成；仍为测试版，实际客户端待玩家测试。

建筑法杖之前只设置单物品堆叠，没有注册最大耐久，也没有在成功建造路径上扣耐久。26.1.2、1.21.11、1.21.8漏31个寻路物品配方，详见本项目BUG-20261005-RECIPE-SYNC-MISSING.md。

本批以各版最后验收代码为基线，增加512耐久、每100个实际变更为非空气的方块扣1点、每把法杖保存余数。成功放置后再付款；空气余位清除、跳过保护、未变更、失败均不扣。创造模式不改变耐久或余数，注册原版耐久附魔标签以支持经验修补。多格结构原子放置后扣耐久，跨最后一点时直接损坏并取消任务；取消之前提出的耐久不足暂停等待修补方案。材料不足暂停规则保持。

修改文件：四版ModItems.java、BuildTaskState.java、WandActions.java；新增BuildWear.java、BuildWandWear.java、BuildWearTest.java；耐久附魔标签、八种语言、说明台新增耐久说明页；三版pathfinding_beacon/recipe新增31个配方；独立服务器WandSmokeChecks增加耐久和真实配方测试；新增玩家数据编辑脚本与回归测试。

已尝试失败：首次隔离服务器只复制eula与server.properties，缺少开发运行目录中的完整Fabric API依赖包，加载器拒绝启动。修复为从对应已验证基线run/mods复制fabric-api归档；26.1.2基线没有该目录，改为从该版实际游戏mods取得唯一已安装API包，并在启动前检查存在与唯一性。禁止删除生产元数据依赖来绕过测试环境缺包。26.1.2配方assemble接口已与26.2一样只接收CraftingInput；首次测试误套旧版双参数签名编译失败，修正测试调用；1.21.x仍使用输入与注册表双参数。1.21.11也已使用Identifier命名，不能仅按26.x判断；测试生成脚本从各版已成功编译的ModItems导入确定标识符类。均未改变实际生产配方实现。

验证计划：纯逻辑100块边界与多格跨界；实际服务器最后1点、原子床、创造不扣、保护/空气/相同方块不扣、真实经验球修补；58个实际RecipeManager配方逐个匹配输入与输出；原31项世界回归及完整单元测试。NBT编辑保持原背包全部字节，拒绝覆盖占用槽位，兼容中文及单人嵌入玩家数据；只在世界session.lock独占成功时写入。

实际结果：26.2为200项、26.1.2为199项、1.21.11和1.21.8各201项单元测试，合计801项通过；每版39项真实世界回归及58项配方检查通过。另6项玩家NBT编辑回归通过。四版运行包、源码归档、完整源码ZIP已生成并保存到本对话H盘交接目录；四个游戏mods目录唯一运行包更新，文件哈希核验一致；确认存档剩余1点耐久建筑杖已写入并重新读取验证，原物品保持。26.2“新的世界 (8)”槽位1（快捷栏第2格），其余三版确认存档槽位9（背包第一格）；26.x仅players/data，1.21.x同时更新playerdata和level.dat内嵌的同UUID玩家。仅保留被修改的玩家文件与level.dat恢复副本，没有完整存档备份。
