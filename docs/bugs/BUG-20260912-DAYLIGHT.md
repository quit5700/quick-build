# 2026-09-12 局部白昼遮挡与自然生成保护

项目根目录：`C:/Users/quit5700/Documents/mc虚拟线路模组/快捷建筑模组`。

## 要求与范围

只修改 mc26.2 原可变恒亮灯的纯局部白昼模式：碰撞形状遮挡直线照明；无遮挡的位置禁止怪物自然生成，作物与真实亮度不变。已有怪物及外界进入不受影响，刷怪笼、袭击、指令和刷怪蛋不受影响。原版和混合模式不变；没有创建或修改复制可变恒亮灯。

## 现象与原因

旧版只按立方体坐标包含关系强制满亮，因此透墙，且没有服务端刷怪保护。用户要求增加新行为，并要求低资源消耗。

## 实现与文件

- `mc26.2/src/main/java/cn/quit5700/light/logic/DaylightVisibility.java`：整数栅格射线遍历，排除灯本体与受光面本身，覆盖负坐标、三轴和边角交点。
- `light/DaylightOcclusion.java`：沿线使用实际碰撞形状求交；同一灯缓存最多 128 个区块段，每段 4096 字节；超出时淘汰较少使用的段，不加载缺失区块，不缓存依赖缺失区块的结果。
- `mixin/DaylightChunkMixin.java` 与区块生命周期事件：碰撞形状改变时清除受影响灯缓存；空气与无形光源替换不触发无用刷新。
- `mixin/NaturalSpawnerMixin.java` 和 `PhantomSpawnerMixin.java`：普通怪物和独立幻翼自然生成入口；只在纯局部白昼无遮挡范围阻止生成。
- `VariableLightTaskState.java`、`VariableLightNetworking.java`、`ClientDaylightState.java`：客户端与服务端共享遮挡算法，快照携带纯局部白昼标记，切换维度重新同步；客户端主线程合并标记区域重建，不调用全局渲染器销毁入口。
- 八种语言说明、`fabric.mod.json`、公共混入配置、版本信息与测试同步更新。网络快照格式有变化，主客机须同时升级。

## 本轮报错与修复

1. 版本接口：26.2 的 `ChunkPos` 坐标为私有字段，首次使用旧 `.x/.z` 导致编译失败。改为 `.x()/.z()` 后针对性测试通过。旧字段方案已尝试失败。
2. Fabric 接口：旧 `ServerEntityWorldChangeEvents` 名称不存在；核对本项目现有 `PlayerEvents.java`，改为 `ServerEntityLevelChangeEvents.AFTER_PLAYER_CHANGE_LEVEL`。旧名称已尝试失败。
3. 测试环境：沙箱 Gradle 下载受限，已通过专用构建权限使用已有缓存。开发服务端缺完整 Fabric API 元模组，使用玩家实例已有 `fabric-api-0.154.0+26.2.jar` 复制到项目独立 `run/mods`；没有改为完整 API 编译依赖，避免已记录的 26.x 转换失败。
4. 中文环境：读取文本显式 UTF-8；编译源码保持 UTF-8。部分 JVM 诊断沿用系统编码造成显示乱码，命令增加控制台 UTF-8；文件路径本身可正常编译与测试。`javap` 内部类名称必须以 PowerShell 单引号包围，反斜杠不用于转义美元符号；旧转义写法已尝试失败。
5. 模型补丁：同一补丁先删除再新增同一路径被工具拒绝，未改变原文件；改为原位更新成功。后续使用更新补丁。
6. 启动日志占用：第一次缺依赖启动未退出，导致第二次帮助模式启动不能轮转同目录日志；帮助模式本身退出码 0。已结束本次遗留启动会话。下次须先确认前次测试进程退出，不并发使用同一 `run/logs`。

## 开销与边界

并非零开销：首次看到未缓存坐标需遍历射线，范围内建造或区块装卸后需重建部分视觉；重复稳定查询使用缓存。碰撞形状作为遮挡依据，所以玻璃等有碰撞的透明方块也会遮挡，液体和无碰撞物体不遮挡。已有灯本体通电亮度 15 的行为保留。
