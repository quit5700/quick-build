# 26.1.2加载地形停在16%

类型：方块实体生命周期、存档加载、区块加载重入。状态：1.1.5八版本代码修复与独立存档回归完成，原玩家世界重进待验收。
当前项目根目录：C:/Users/quit5700/Documents/mc虚拟线路模组/快捷建筑模组。

现象：正式版1.1.4进入现有世界，加载49个出生点区块停在16%。两次活动游戏线程快照显示相同服务端调用栈。

根因：VariableConstantLightBlockEntity.setLevel第94行在旧灯模式迁移时直接调用setChanged。引擎随后通过Level.blockEntityChanged、getChunkAt、ServerChunkCache.getChunk同步等待当前区块；当前区块还在runPostLoad/方块实体注册中，造成区块加载重入等待。客户端仍在绘制LevelLoadingScreen，不是客户端绘制线程停止。已有BUG-20260913-LIGHT-INIT-REENTRY记录的是另一入口重查自身；本次不能只沿用对象入口修复，因为setChanged仍隐含区块查询。

代码核查：同一路径也存在于正式26.2和旧1.1.3的26.1.2；不能把此次法杖按钮或纹理修改当作根因。当前触发了retiredMode旧灯迁移分支。尚未检查完所有版本，不断言其他版本都正常。

推荐修复：初始化期间只更新当前灯对象及迁移状态，将必要的脏标记推迟到区块完成加载后的安全入口；检查迁移过程中其他调用是否也隐含区块查询。保留原灯配置、光源与存档，不删除灯、不修改存档。增加含旧模式灯的区块重载回归；普通放置和首次创建世界不能代替该验证。

证据：outputs/诊断_26.1.2地形加载_20261005/线程快照_1.txt与线程快照_2.txt；玩家日志01:53:43开始加载49区块，01:53:44仍16%。该段为定位时状态；后续处理已获用户授权，最终验证见下文。
