现象：用户报告有生成箱却没有虚拟高亮。测试16小选区曾显示，不能代表其他蓝图并存时正常。
复现：基于原测试16原生产源，在真实26.3客户端加入128³其他虚拟蓝图，再创建5格建筑箱任务；客户端已收到高亮行后8游戏刻，真实绘制提交不含应有22面，断言失败。日志 versions/1.1.9-test16/渲染_mc26.3_2.log，独立复现脚本 scripts/repro_projection_test17.py，未读写用户存档。此复现证明存在缺陷，用户具体使用版本仍待回复，不将推断冒充用户原场景。

修改：十版各自AuxRenderer.java、BuildProjection.java、AuxServer.java、BuildTaskState.java、BuildProjectionTest.java。保留本版渲染和存档接口。建筑投影优先遍历，其他网格未完成时仍提交当前已生成的建筑面；每帧仍按最新任务与游标过滤。箱子创建使用实际游标/方向/模式初始化完整高亮信息后再同步。结束/取消沿用同一任务清理和最新任务过滤，不改变耗材/退款/耐久。

验证：原真实客户端复现失败已记录；新增排序自动回归，首次箱子完整信息、实际反向游标/中空模式、真实画面出现、空手保留、进度、取消、真实5块建造完成后箱子与高亮清除将逐版验证，未完成前不宣称全部修复。
