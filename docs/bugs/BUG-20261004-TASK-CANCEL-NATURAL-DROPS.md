# 建造任务取消、余位容器及自然掉落

当前项目根目录：C:/Users/quit5700/Documents/mc虚拟线路模组/快捷建筑模组。
分类：任务保存/取消、容器数据和掉落、自然更新、26.2接口迁移及界面文字。版本1.1.4-test11/mc26.2，正在处理。
根因：旧取消依赖对应法杖身份，遗失后保留任务但不能启动新任务；旧多格余位拒绝覆盖方块实体，旧严格支撑检查与用户最新要求不符；部分原说明与多格材料、空心厚度不一致。
已尝试失败：ServerPlayer.getServer（服务端玩家获取服务器）在26.2不存在，编译失败；改为明确ServerLevel（服务端世界）获取getServer，不重复旧玩家接口。只读查找曾误假定SettingsNetworking与client/BuildingWandClient路径，实际设置使用WandNetworking，初始化类位于buildingwand包根；后续先rg定位。
方案：专用网络请求仅按已认证玩家身份取消跨维度建筑任务，并返回实际数量；释放区块、清理选区/闪烁，保留已完成部分，不取消其他玩家或删除任务。实心/空心余位允许覆盖容器，内容先按游戏容器规则掉落并清空，随后设空气，防止重复掉落；区域替换保护保留。自然放置不因支撑暂停，整组先装配，再用原版形状与破坏方法处理失效，正常扣物品。兼容具有标准上下两格/床式两格属性的模组方块。旧严格装配方法保留为内部回滚校验，玩家任务调用自然放置方法。
验证：待完整测试与独立世界回归，不宣称已修复。

首轮世界测试中两个取消场景因测试使用lost等非法法杖标识失败；DeleteTaskData要求合法UUID（通用唯一标识），改用真实UUID准备任务，不放宽原校验。自然掉落、余位内容精确掉落和模组属性双格放置场景已通过。模组属性双格也同步纳入原有区域替换保护，避免破坏已有结构。

修改文件：BuildTaskState、BuildWandServer、BuildNetworking、BuildingWandClient初始化、BuildWandClient、WandSettingsScreen、SettingsScreenLayout、StructurePlacement、WandActions单块分支、ReplacementRules、八语言、SettingsCancellationLayoutTest、独立世界WandSmokeChecks、版本属性及说明。
具体实现：取消以连接身份为准，不接受客户端指定其他玩家；所有维度按任务owner（所属玩家）清理并释放租用区块，响应数量清理客户端选区。余位容器掉落后立即清空再设空气；自然放置调用Block.updateOrDestroy（原版形状更新和破坏），不恢复已经自然掉落的材料，避免重复产物。模组双格按标准属性识别并受保护。
验证：新增2项按钮布局测试，原181项测试预期保留；27项独立世界回归通过，测试取消跨维度/多杖/本人隔离/重复取消/保存恢复/丢失法杖、无支撑门和植物及火把真实掉落且扣材料、实心空心余位内容13钻石7金锭精确掉落并重复执行不复制、区域替换余位容器内容保留、非门类模组两格完整状态/材料/保护。玩家真实界面待验收。
防回归：不得接受客户端传入取消他人身份；取消必须释放区块并让保存数据更新；内容掉落后必须清空，不能再让旧容器重复掉落；自然掉落不能触发退款、回滚或重新放置；标准属性识别不等于所有私有模组结构自动支持；旧严格回滚方法只作内部独立验证，实际玩家调用自然模式。
