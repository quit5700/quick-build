## 范围与设计

形状菜单把信标塔放在金字塔后，存档编号追加12，不重排旧0至11编号；菜单单独维护显示顺序。按选区宽、高、深容纳1至4层实心原版底座，顶部中央加一个信标。高度包含信标，最小3×2×3，四层9×5×9；过大范围居中容纳完整原版结构，不无限扩大，不以半格对齐。不依赖两点先后来倒置信标塔。

默认底座铁块，材料页仅列铁、金、钻石、绿宝石、下界合金块，顶部信标独立计算。层数对应底座9/34/83/164个块，各需1信标；不消耗铁锭等中间材料代替完整方块。原版要求实心底座，信标塔禁用空心选择；微调删格仍可删，但修改后是否激活遵循原版规则。默认颜色和选中高亮保持，实际材料预览、旋转/移动、文件保存读取和生成箱沿用既有链路。未新增自定义方块、物品、配方或材质。

上方遮挡、天空可见、支付激活材料及效果选择由原版信标处理，不自动选择效果，不承诺被遮挡或侧倒时仍有光束。
