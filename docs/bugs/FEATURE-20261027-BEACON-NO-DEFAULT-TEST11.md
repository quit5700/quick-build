# 测试11：信标塔不设默认材料并同步十版本

用户明确要求：信标塔不要默认材料；先改26.3，再同步常用十版本；处理完本批且另一个指定对话也完成后才关机。当前版本为1.1.9-test11（测试11），未经用户确认不生成正式版。

## 行为

新建信标塔、旧记录没有Material字段或字段为空时，底座和顶部均不附带真实材料，仅显示纯色虚拟投影，生成按钮不可用且服务端拒绝创建任务。明确选定的铁、金、钻石、绿宝石、下界合金底座之一继续保留；选定后顶部独立需要一个原版信标。清空材料恢复未选择，不恢复铁块。纯色结构文件保留形状和选区，但不导出隐含铁块或信标。

保持测试10规则：按宽、高、深可容纳的最大完整层数生成，无建筑四层上限；顶层3×3实心平台和一个信标；原版效果仍最多四级。已创建任务的计划、需求和投入不自动改写；旧版原生任务字段需正确解码。

## 改动

AuxBeacon、AuxFiles、AuxServer、AuxScreens及八语言帮助文字。默认材料回归测试区分未选材和明确选材；旧有计料测试显式选择铁块，保留其正确预期。九个旧版另外适配原生Name/Properties任务状态，见BUG-20261027-TEST11-VERSION-PORT.md。

版本范围：1.20.1、1.20.4、1.21.1、1.21.4、1.21.8、1.21.10、1.21.11、26.1.2、26.2、26.3。每版独立源码、构建、资源与存档接口；安装目录从当前已核实清单读取，1.21.10为用户指定“1.21.10服务器”Fabric实例，26.3固定“26.3-Fabric”。
