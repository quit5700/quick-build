# 区域替换重复红色警告

项目根目录：C:/Users/quit5700/Documents/mc虚拟线路模组/快捷建筑模组。
类型：客户端显示、服务端消息重复。
现象：用户截图中浅蓝提示下居中红字与左下聊天红字内容相同，要求只保留居中行，时长改5秒。
根因：test6引入独立BuildWarningHud，但保留BuildWandServer.warnMultiple中sendSystemMessage同一保护警告，原版聊天与独立警告同时显示。四版源路径一致。不是HUD注册两次，也不是换行产生第二份。
修改文件：四版BuildWandServer.java删除该保护警告聊天分支、BuildWarningHud.java仅6秒常量改5秒；WandSmokeChecks.java按新要求验证无聊天重复，同时验证独立State.warning仍传递。其余生产文件和资源逐字节核验与test7相同。
验证：实际服务器原54项逐版通过；保护箱子、火把材料、浅蓝提示检查中聊天无重复，材料选择与网络警告字段仍有效；完整单元和构建通过。未移除多格警告或其它聊天信息，没有弱化不相关旧测试。
防重复：独立提示与聊天若发送同一警告即会出现截图这种重复；不能为去重复关闭独立警告或改动材料、保护规则。原先保留聊天记录导致画面重复，标记为已尝试失败。本次仅源路径和服务器验证，实际客户端5秒画面未实机验证。
