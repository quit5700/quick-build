# 26.3辅助魔杖与生成箱实现及防回归记录

问题类型：版本接口、数据保存、渲染、材料守恒、核心建造逻辑。

现象与根因：26.3普通模型提交最后一个整数是描边颜色而非透明度，旧理解会造成错误画面；箱子等特殊模型可能返回非空但无几何的模型部件，不能以列表非空判断可绘制。方块实体提取参数需匹配渲染器离屏类型，不能一律true。分批建造提前更新邻居会破坏尚未放置支撑的部件或使水外漏。空心床仅保留壳上格会丢失内侧伙伴；直接以格数算材料会把一张床扣成两张。全量状态回传或深复制大计划会浪费内存；带库存潜影盒按普通物料收取会丢失内容。

涉及文件：test5/mc26.3/src下aux包（AuxRow、AuxMaterials、AuxPlacement、AuxTransforms、AuxState、AuxNet、AuxServer、AuxClient、AuxRenderer、AuxFiles、AuxScreens、AuxMouseMixin），注册与交互入口、说明台、物品页、配方、模型材质和八语言文件；AuxRowTest、AuxTransferTest；scripts/probe_aux_test5.py、probe_aux_final_visual.py及独立验证源码。

修复：普通模型重包透明材质；检查实际四边形再决定普通/特殊渲染路径，使用独立姿态栈及正确提取类型。虚拟形状参数化、稀疏导入和写时复制，任务回传只发摘要。变换先全部校验再提交，数据按玩家及维度隔离。预览、导出、生成共用材料布局，床/门完整单元和余位一致，按物品计费。逐单元静默放置与回滚，全部完成后分批更新支撑、红石、连接及流体。任务/材料/退款队列持久化，带库存材料拒收，空容器允许，退款物品分批掉落。

已尝试失败：以模型部件列表非空判定普通模型可画；将方块实体提取布尔值一律true；误认26.3床仍是方块实体并要求错误的渲染路径标记，原生类检查证明BedBlock现在使用普通几何；据此修正探针，未为错误预期改写床模型。后续必须检查床普通模型和箱子特殊模型的成功标记并保留画面。26.3彩色床常量不可沿用旧版本，测试按注册表标识获取。开发探针不得进入交付包。

验证：250项单元、59项旧功能世界回归、60配方；实际客户端26项功能场景，以及追加床/箱原生渲染、潜影盒库存防丢验证通过。完整日志、截图和独立探针保留在versions/1.1.9-test5及outputs/20261025_辅助魔杖验证。其他八版本按已交付运行包SHA256（摘要）逐一核验未改。

避免重复：真实世界状态以服务端为准；多格材料共用布局；不要每帧复制结构或每次进度回传整份计划；更新支撑须在完整建筑安装之后；不把编译通过当成模型显示或存档恢复通过。安装跨盘备份使用复制与摘要核验，不使用跨盘rename（改名）。
