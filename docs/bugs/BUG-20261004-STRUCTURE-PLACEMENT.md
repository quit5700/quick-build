# 特殊结构放置与箱子邻接保护

当前项目根目录：C:/Users/quit5700/Documents/mc虚拟线路模组/快捷建筑模组。
分类：核心放置逻辑、状态/任务保存、邻接保护、玩家提示。版本1.1.4-test10/mc26.2。

现象：旧建筑仅按默认方块状态直接写入，不能自动成组放床、门或双格植物；没有主动校正栅栏、墙和玻璃板连接。密集箱子需验证为单箱。新增独立世界用连续泥土替换为空箱，第二格被跳过。
根因：原选择只保存方块种类，放置缺少两格结构规划和完整装配；ReplacementRules把所有受保护邻居在全部六个方向都当成附着物，把水平方向相邻箱子误判为依赖下一格泥土支撑。

修改文件：新增StructureLayout（结构布局）、StructurePlacement（结构放置）、StructureLayoutTest（结构布局测试）；BuildTaskState、BuildWandServer、WandActions的单块放置分支、ReplacementRules、WandSettingsScreen、八语言、独立世界WandSmokeChecks、版本与交付说明。移动快照及删除核心保持。
修复：常量空间两格布局从第一点方向成组排列，实心末端空气、空心外壳向内厚度、用户确认的49×49等奇数末端留空。完整结构先装配再检查生存条件并通知，失败恢复原位置，不扣材料；每完整物品耗一个材料，缺料暂停，补料继续。普通方块保留原版更新和回调；箱子保持SINGLE（单箱）；连接方块和边界邻居主动校正。区域替换整组过滤、保护与警告，允许确认继续，不绕过保护。保护附着物与红石/工作方块底座，不把水平相邻普通箱子当成附着支撑；补测墙面按钮支撑。
说明台明确：放入箱子等受保护方块后，无法再用区域替换替换。两点警告采用现有左键确认/右键取消，不增加界面控件；八语言同步。

已尝试失败：开发途中新增翻译键尚未写入语言资源，179项测试中语言校验失败，补齐八语言后通过，未放宽测试。首轮独立世界21场景中两个失败：箱子测试准备上层支撑时覆盖了下层箱子，修正夹具为先准备完整空间再放置，原单箱断言不变；连续箱子替换暴露上述旧支撑误判，最小修正后21场景通过。不能依据Gradle（构建工具）成功退出判断世界回归成功，须检查Q5_CASE_FAIL与最终PASS（通过）标记。

验证：保留原173项测试，增加8项几何回归，包括49格、正反方向、空心厚度、奇数末端、垂直配对、整数极值及数百种尺寸/模式/方向的计数与枚举比对。独立世界新增8场景，覆盖连接与边界、18个密集单箱、完整床/门/植物及失败恢复、49×49和反向建造、空心内部保留与实际放置数量、缺料整组暂停补料、保护整组跳过与警告继续、生成箱子再次替换保护、红石/按钮支撑。原13场景继续执行。

下次避免：不能用默认状态写入代替完整多格结构；不能先扣材料再发现放置失效；空心多格进度分母必须含结构厚度；支撑保护应区分真实附着方向和普通水平邻居；不得为了修连接改变普通方块物理、移动或删除逻辑；跨区块组只加载相关两格，不展开整个区域到内存。未知模组私有结构不能承诺自动支持。
未验证风险：真实客户端外观、说明台长文字、其他模组私有多格设备和大规模实机性能；门/植物仍须满足游戏生存条件，否则任务暂停，可补支撑后继续或右键取消。

最终核验：完整清理构建成功，181项测试全部通过；21项独立世界回归通过且无失败标记；八语言键集合和参数一致；原173项测试文件未修改，移动快照逻辑及删除核心代码未变；成品不含世界测试类。真实客户端待用户验收。
